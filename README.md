# Fidget Spinner

A collection of custom, 3D-printable fidget spinners designed from scratch. Each folder includes ready-to-print `.3mf` files, renders, a walkthrough video, and an assembly guide so you can easily print and build your own.

## Fidget Spinners
- **[Demon Slayer Inspired Fidget Spinner](https://github.com/NivedhGovil/Fidget-Spinner/tree/main/Demon%20Slayer%20inspired%20fidget%20spinner)** — A multi-part spinner inspired by *Demon Slayer*, complete with `.3mf` print files, renders, a walkthrough video, and a `GUIDE.md` assembly manual.

## Getting Started
1. Open a spinner folder above and check its `GUIDE.md` for print settings and required hardware (such as standard 608 bearings).
2. Slice and print the `.3mf` files, then follow the guide or walkthrough video to assemble.
